# BigTrooper

## Purpose

This project is a web app that allows users to make QR code based 3D printable pet tags for their pets. If a pet is lost the tag can be used to notify the owner of the pet's location.

## Technologies

- React (frontend)
- Go (backend)
- PostgreSQL (database)
- Docker (containerization - DB only for now)

## Setup

Copy [`.env.example`](.env.example) to `.env` and fill in the values. Every variable is explained in that file.
